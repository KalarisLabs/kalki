# Getting help

| You have | Go to |
|---|---|
| A question, or an idea you want to discuss | [GitHub Discussions](https://github.com/KalarisLabs/kalki/discussions) |
| A bug you can reproduce | [Open a bug report](https://github.com/KalarisLabs/kalki/issues/new/choose) |
| A security vulnerability | [SECURITY.md](SECURITY.md). Report it privately. |
| A conduct concern | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Before you file a bug, run `kalki doctor` and include its output.

Kalki is pre-release software maintained by a small team. There is no paid
support and no response-time guarantee.
